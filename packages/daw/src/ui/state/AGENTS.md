# packages/daw/src/ui/state

Solid stores and signals: song store and restore (`song.ts`), undo history and snapshots, view/arrangement/device/transport/live/layout/audition state, persistence helper. Display state, never song state, except `song.ts`.

| File | Purpose |
|---|---|
| `arrange.test.ts` | Unit: row heights, window at top / scrolled, pinned rows, segments keep offsets + total height. |
| `arrange.ts` | Arrangement view state (daw-solid-ts 5.2): `TRACK_H` 56 / `AUTO_H` 40 / `ADD_H` 24, `rowHeight(open, lanes)`, `windowRows(heights, top, view, pinned)` (view ± one screen + pinned, ascending), `segments(heights, rows)` (rows + `{gap}`); `barWindow(left, view, bw)`; store `laneVer` + `bumpLane(id)` (renderLane); signals `bw`, `scrollLeft`, `viewW`, `scrollTop`, `viewH`, `armedId`, `focusedId`, `renamingId`, `rev` (rebuildTracks), `labelRev` (renderAll). 9.5: `trackRev(id)`/`bumpTracks(ids)` per-track refill counters; `laneBars` memo (bars lanes build handles for: `barWindow`, all until `viewW` known). |
| `audition.ts` | Audition signals (daw-solid-ts 8.2): `kbOn`, `kbOct` (0–8, default 4), `kbVel` (1–127, default 100) with clamping setters, `midiText`, `mw`, `pb`. Live only: not in song, not undoable, not remembered. |
| `device.ts` | Device view state (daw-solid-ts 6.2): `setAuto(values, field, v, ovr)` / `autoValue` / `autoOverridden` (store per raw `values` object, write only on change), `shownTrack`/`setShownTrack` (renderDevice publishes `selected`), `slotOpenOf`/`setSlotOpen` (session), `blockClosed`/`setBlockClosed` (`daw.blk.<k>` via `setPersist`), `deviceShown`/`setDeviceShown`. Block collapse persists via `state/persist.ts` (`setPersist` removed, daw-solid-ts 8.2). |
| `files.ts` | Files state (daw-solid-ts 4.2): signals `songs` (sorted paths, `addSong`), `songFile`, `dirty` {on, n}; `base`, `saveLabel(file, dirty)`. ui/app/files.ts publishes (start, `useSong`, save, `dirtyUpd`). |
| `history.test.ts` | Unit: no-op gesture not committed, undo/redo exact `toSong`, restore keeps track/device/values identity and track order by id, restore touches only tracks + master, state ids (undo to saved = same id). |
| `history.ts` | `createHistory()` (daw-solid-ts D2): `commit(before, after)` (drops unchanged), `undo(now)`/`redo(now)` → snapshot to restore or null, `clear()`, `depth`, `canRedo`, `stateId` (unsaved = id ≠ id at save; no snapshot compare per edit). |
| `layout.ts` | `sizeOf(cssVar)` (daw-solid-ts 8.2): splitter size signal per root CSS var, applied to `document.documentElement` and remembered as `daw<var>` = `"<n>px"` (same keys as before the port). |
| `library.test.ts` | Unit: items + tags per source, visible sources, search + open groups, inspector facts (loadable, legacy, conversion note). |
| `library.ts` | Library state (daw-solid-ts 4.2): `SOURCES`, `LIST_CAP` 300; pure `libItems(cat, src)`, `visibleSources(cat)`, `filterItems(items, q)` (name+tag), `openGroups(cat, q, want)`, `describe(src, it, hasInst)` → {what, legacy, canLoad, conv}; signals `catalog`, `query`, `current`, store `open` per source. |
| `live.test.ts` | Unit (real Solid runtime via the test preload): unchanged pos/playing/load do not notify; a meter notifies only beyond `PEAK_STEP`, per track. Run from the repo root (root bunfig preload). |
| `live.ts` | Display state at frame rate (daw-solid-ts D3): signals `pos` (bars), `playing`, `load` (%), store `peaks` by track id + `setPeak(id, l, r)` (only beyond `PEAK_STEP` 2e-3). Written by the session (`showPos`, `setPlay`, `setLoad`, `meters`; imported as `liveState`, `live` is the aria-live element). Never song/undo/engine state. |
| `persist.ts` | `persist` (daw-solid-ts 8.2): localStorage get/set with memory fallback (sandboxed frame); used by ui/app/device.ts (`store`: Live toggle), `device.ts` block collapse, `layout.ts`. |
| `snapshot.test.ts` | 5 tests: round trip, cache reuse + copy-on-write seen, verify throws on in-place edit, restoreSong drops cache + priming, source scan: no in-place `ln.pts` writes in src/ui. |
| `snapshot.ts` | Undo snapshots (daw-solid-ts 9.3, D2): `Snap` {epoch, meta, tracks/master `TrackSnap` {id, body (track w/o lanes), lanes (headers w/o pts), pts[] (per-lane JSON)}}; `makeSnap`, `snapEqual`/`trackSnapEqual`, `snapState`/`trackState`, `primeSnap`, `resetSnapCache`, `setVerify`, `snapStats`. Lane pts cached per array (WeakMap). Invariant: pts never changed in place (copy-on-write); verify mode throws on a stale cached lane. |
| `song.ts` | Song store, transition phase (daw-solid-ts D2): `createSong(st)` = `createMutable({tracks, master})` (the session modules in ui/app/ mutate the proxies; writes notify), `raw(x)` = O(1) `$RAW` target (never Solid `unwrap`: deep-walks non-proxies), re-exports `batch`; `restoreSong(song, d)` = `modifyMutable` + `reconcile` of `tracks` (key `id`) then `master`, never the root. Bulk readers (snap, `uiState`/export, `structuredClone`, thumbnails, `modeOf`/`tableOf`) use `raw`. Becomes `createStore` + actions when the write ratchet reaches 0. `restoreSong` drops the snapshot cache; `restoreTracks(song, [[i, t]], master?)` reconciles only some tracks (9.3). |
| `transport.test.ts` | Unit: `fmtPos` (4/4, 3/4, 7/8, before bar 1), `fmtTime` (tempo, signature), `ensureSig` adds once. |
| `transport.ts` | Transport state (daw-solid-ts 3.3): signals `tempo`, `sig` + `sigOptions` (`ensureSig`), `snap` (`SNAPS`), `bars`, `loop` [a, b) + `loopOn`, `follow` + `followHeld`, `rec`, `edited`, `drops` ({n, title} or null), `buffer` (`BUFFERS`), `openFilters`; pure `fmtPos(bars, sig)`, `fmtTime(bars, bpm, sig)`, `quartersPerBar`. ui/app/ (transport, engine, arrange) publishes loop/bars/follow/rec/edited/drops; reads tempo/sig/snap/buffer/openFilters. |
| `view.ts` | Editor view state off the song objects, by track id (daw-solid-ts D2): signal `selectedId` (set by `selectTrack`), `laneEl` (lane element), `overrides` + `overrideSet(id)` (hand-overridden automation keys `dev:param`; cleared by undo `restore()` as before), `rollClips` (clip last opened in the roll). Not saved, not undoable. `rollShown`/`setRollShown` (daw-solid-ts 7.2: roll panel mounted only while shown). |
