# packages/daw/src/ui/model

Pure model helpers (no DOM, no store writes except where noted): parameter tables and formatting, track/device helpers, base64 and GM helpers.

| File | Purpose |
|---|---|
| `bytes.ts` | `b64ToBytes`, `bytesToB64` (32 KB chunks), `gmInstrument(idx)` (1-based GM.DLS index: drums from 16385, bank×128+prog). daw-solid-ts 9.1 step 1. |
| `params.test.ts` | Unit tests of params/track/bytes on the real engine tables (instantiates `synth.wasm` from `buildSynthWasm()`, `song_tables`/`song_physical`): choice, ip/optName/oscType/slotUsed, effect modes, fmtVal/panText, envelopes, engineDev/patOf/cleanDev, base64/GM. add-fudge-softsynth: engine kinds by label, units, defaults; drawing vs engine frames (Fudge 1, 17, 8); 7 gaps. |
| `params.ts` | Device parameters from the engine tables (daw-solid-ts 9.1 step 1): `initParams(tables, physical)` once; `SLOTS`, `choice`, `nModes`, `modeOf`/`tableOf` (raw reads), `paramOf`, `devName`, `autoParams`, `effectChoices`, `INST`, `ip` (name map built at init), `vget`, `optName`, `envRate`, `oscType`, `smpShapes`, `slotKeys`, `TARGETS`, `modSrcName`, `routesOf`, `slotUsed`, `envMs`, `tfEnvSeconds`, `envCurve`, `panText`, `fmtVal` (proxy reads: knob text tracks law/sustain/slope/osc type). `optValue(name, label)` (stored value of an option); `oscType` over the 13 v3 kinds (5–11 naive, 12 clocked). See change: unify-v2-algorithms 6.5–6.8 (the format switch). 9.4: `slotKeys` cached per instrument table (returned arrays shared: do not mutate).; `oscType(d, i)` maps the osc type's option label to the DAW kind index (0 Off … 4 Sampler … 12 Clocked, 13 Points, 14 PAD table; not the engine's stored position), `GAP` ("—", a free position of an expanded choice). See change: add-tf3-import 2.1. `loadTime(d, p)` (structural, or a PAD slot's table input `osc<i>.s0`–`s4`; mirrors unisynth `params::is_load_time`): `autoParams` leaves them out; `PAD_PROFILES` (single, detune, spread, gauss: `fmtVal` of a PAD slot's s4); `pointCycle(count, offset, value, modes)` → 257-sample cycle + point marks, the engine's `pts::cycle` (phantom (0,0), natural spline, step/linear/spline segments, mean removed; params.test.ts holds engine fixtures). See change: add-tf3-import 6.3 `modeOf` decodes the stored mode position through `BY_POS` (each effect table's mode default = its stored value; the engine expanded the distortion/EQ/delay choices) and `modeValue(kind, mode)` encodes it; `oscType` 15 = Pair; `fmtVal` formats `LinTime`, `DropHz`, `DropRate` (halving time) and a linear envelope's A/D/R without the 1 ms floor. See change: add-elevated-import. add-fudge-softsynth: `oscType` 16 Shaper tone, 17 Sweep drum; `oscKindOf(v)`; `TONE`/`DRUM`, `engineValue`/`engineText` (D3 laws in units; `fmtVal` uses them for an engine slot's `s0`–`s8`), `DRUM_CURVES`, `typeDefaults(kind, i)` (Fudge instrument 1 / 8), `engineFrames(kind, shapes, n)` (TS mirror of `osc::engine`, truncating f32 via `DataView`; drawing, ≤ 2 LSB). |
| `track.ts` | Track helpers (daw-solid-ts 9.1 step 1): `instOf`, `fxOf`, `devicesOf`, `links`, `engineDev` (bypassed left out), `cleanDev` (drops `_edited`/`_dev`; `UIDevice`), `laneText`, `patOf` (creates a missing pattern: a model write), `carry`. |
