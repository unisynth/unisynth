# packages/daw/src/ui

SolidJS UI of the DAW (change daw-solid-ts; TypeScript strict). `App.tsx` `start(daw)` mounts every panel and wires the session modules in `app/`. Components read the song through the store (`state/song.ts`); view state lives in `state/`; pure model helpers in `model/`. Docs: `docs/synth/daw.md` "UI structure".

| File | Purpose |
|---|---|
| `App.tsx` | `start(daw)` (daw-solid-ts 9.1 step 9; replaced `app.js`, whose history is in git): `initSession`, params, then mounts transport bar (first: rest finds its ids), files, library, track rows (`WithTrack` actions), mixer, audition footer, splitters, tabs, shortcuts, roll panel (last: its mount setups are bound) and wires them to `ui/app/*` init hooks; `onTempo`/`onSig`; `daw.debug` (song, selected, bars, undoDepth, live). 9.3: `setVerify` from `persist` `daw.verifySnap` (default on under `navigator.webdriver`), warm `snap()` after `markClean`. |
| `keys.ts` | `installKeys(KeyActions)` (daw-solid-ts 8.1, D7): every global shortcut in one table, two phases. Window capture (before the focused editor): Ctrl/⌘+S, \` toggles the computer keyboard, its note (`KB_LO`/`KB_HI`, `kbNote` by `e.code`), octave and velocity keys while `kbPlays()` and no modifier/typing/menu; keyup releases, window blur = all notes off. Document bubble (after the editor): Ctrl/⌘+Z/Shift+Z/Y unless `defaultPrevented` or in a text input; outside inputs/selects: Space, Home, L, Ctrl+L, F, Shift+R (not on a slider), then +/−/Shift+Z zoom/fit by `inRoll(e)`. Returns uninstall. |
| `mixer-store.ts` | Mixer UI state (daw-solid-ts): `MixerActions` (select, openInsert, bypass, effects, addInsert, sendTargets, addSend, removeSend, `sendLevel(id, i, db, done)`, addBus, `devName`), signal `shown` + `setMixerShown`. Separate module so component hot reload keeps state. Bridge (`syncMixer`/`patchStrip`/`patchSend`) removed in 2.6. |
| `mixer.tsx` | SolidJS Mixer (daw-solid-ts): `mountMixer(el, song, actions)` renders `<Show when={shown}>` (hidden tab = no DOM); `Strip` reads the song store track proxy directly (name, col, vol, mute, solo, devices → inserts with bypass, sends tuples), `sel` from `state/view.ts` `selectedId`; `Picker` (button → select, blur restores); `Meter` binds `state/live.ts` `peaks[id]`. Fader and mute/solo call `MixerActions` (ui/app/mixer.ts → tracks.ts `setVolume`/`toggleMuteSolo`: one undo per fader gesture, mute deferred commit, solo none); the header follows the store. |
| `zoom.test.ts` | Unit: `anchorScroll` keeps content under anchor; `wheelF` notch/line mode/clamp; `clamp`. |
| `zoom.ts` | Anchored zoom math (daw-solid-ts 8.2): `clamp`, `wheelF(e)` (wheel/pinch factor), `anchorScroll(scroll, anchor, u0, u1)`; used by ui/app/arrange.ts `zoomArr` and ui/app/roll.ts `zoomRoll`. Tests: `zoom.test.ts`. |
