# packages/daw/src/ui/arrange

Arrangement components: track headers and lanes (`Tracks.tsx`, windowed rows), clips, thumbnails, automation lane point selection (`lanePlot.ts`).

| File | Purpose |
|---|---|
| `Clip.tsx` | `Clip` (daw-solid-ts 5.3): `.clip` with reactive left/width (`bw`), `linked`/`sel`, label, ARIA label; `_clip` on the element for the lane pointer handlers (ui/app/clips.ts); `<canvas class="notes">` thumbnail drawn from `thumb()` when `laneVer[t.id]`, len, loop, name or zoom change (deferred while scrolling); `PatternOf` reads the pattern without creating it. |
| `Tracks.tsx` | `mountTracks(hdrs, lanes, scroller, tracks, actions)` (daw-solid-ts 5.2, D6): windowed rows in two columns (`#hdrs`, `#lanes > .rows`), `.gap` spacers keep offsets + scroll extent; header (`.thdr.track`, M/S/arm/A, volume, name + `Rename` input, `err` + title from validation, device label on `labelRev`) and lane (`.lane.track`, `.sel`, opacity when muted, static bus note) reactive on the song store + view state. Lanes render `Clip`s culled to `barWindow` (view-width pages ± 1), only while in the view window (pinned-only rows stay empty); `laneEl` registered by the lane. Open automation group: `mapArray(t.lanes)` → `autoLane(t, ln)` pairs (`ah` in `#hdrs`, `al` in `#lanes`) + '+ lane' row (`addAutoLane`); adding/removing a lane needs no rebuild; refilled on `rev` (undo reconciles lanes by position). Rows entering on scroll fill / draw from a 6 ms/frame queue. `TrackActions` devLabel, about, rename, pattern, autoLane, addAutoLane, mute, solo, arm, volume (live / `done` = one undo step), click, key (native `on:keydown` on the header: target-phase order kept), menu, startRename (daw-solid-ts 5.4: no document delegates). No `aria-posinset`: not allowed on `role=group`. 9.5: `AutoGroup` refills on `rev` or its track's `trackRev`. |
| `lanePlot.test.ts` | Unit: sparse lane keeps every point; dense keeps extremes and ends; window bounds handles, line one neighbour beyond; `laneLine` thinning. |
| `lanePlot.ts` | Which automation points a lane draws (daw-solid-ts 9.5): `laneLine(pts, x)` (whole line, first/lowest/highest/last per pixel column), `lanePlot(pts, w0, w1, x, handlePx, sel)` → `{ line, handles }` (handles: lowest + highest per `handlePx` column, bars in `[w0, w1]` only, `sel` always kept). Pure; points sorted by bar. |
| `thumb.test.ts` | Unit: note rects (x, y over pitch range, min width), loop repeats + marks, cropped clip, empty. |
| `thumb.ts` | `thumb(notes, {len, loop, patLen, w, h})` → note rects + loop marks: the old per-note `<i>` layout for one canvas per clip (pure). |
