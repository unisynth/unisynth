# packages/daw

Browser DAW for the unified synth (change add-synth-daw, spec synth-daw), served by `packages/cli` at `/daw/`. Plain TypeScript + DOM, migrating panel by panel to SolidJS (change daw-solid-ts: Mixer done, `src/ui/`); the UI is the reviewed mockup (`openspec/changes/archive/2026-10-30-add-synth-daw/mockup/index.html`) ported into `src/app.js` on the real model and engine; `src/app.js` is now the source (edit it, not the mockup). Build: `bun packages/daw/build.ts` (also `pnpm -r build`). Dev with hot reload: `bun packages/cli/src/cli.ts serve --port 6474 --no-headless` + `DAW_API=http://127.0.0.1:6474 pnpm --filter @64k/daw dev` → http://127.0.0.1:6465/daw/. Docs: `docs/synth/daw.md`.
