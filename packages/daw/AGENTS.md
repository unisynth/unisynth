# packages/daw

Browser DAW for the unified synth (change add-synth-daw, spec synth-daw), served by `packages/cli` at `/daw/`. Plain TypeScript + DOM (no framework); the UI is the reviewed mockup (`openspec/changes/add-synth-daw/mockup/index.html`) ported into `src/app.js` on the real model and engine; `src/app.js` is now the source (edit it, not the mockup). Build: `bun packages/daw/build.ts` (also `pnpm -r build`). Docs: `docs/synth/daw.md`.

Per frame: `showPos` reads scroll before writes, writes changed text only; `applyAutomation` writes knobs only on change; `meters` touch DOM only on visible change (cached by `#mixer` MutationObserver); engine readout = ~0.5 s mean of `load`. `#buffer` select (Low/Normal/Safe/Max, stored `daw.buffer`) restarts audio keeping position and play state. `pushSong` queued (a push during a push runs again after it; never dropped); status `playing:false` stops the UI only for the current `gen`; dead engine → stop, 0% readout, message, Play restarts. Piano roll + controller canvases cover only the visible part (`rollView`, `rollX0` offset, `.roll-size` sizers keep scroll width, redraw on scroll/resize): a 118-bar 950-note clip opens in ~0.3 s. Tracks with automation open their lanes on load (`t.open` default); lanes `role="group"`. Loop off by default; Follow (⇥ Follow) pages at the right edge and a hand-scroll pause resumes when the playhead reaches the edge. Automation record (`#rec`, Shift+R, `recordPoint`): 1/64-bar touch writes, lane created + shown, no override, pushes ≤ every 200 ms, held knob writes every frame (`recHold`), one undo per gesture. Sampler slot (`samplerPre`): source select `osc<i>.s7` = choice of 3 (GSM sample 0, GM instrument 0.5, GM wave 1.0), index `osc<i>.sample` (raw, number field "sample #"; `s7`/`s8` knobs dropped); shows "GSM sample N of M in this instrument", GM instrument name/bank/program/regions, or wave. GM library load → GM-instrument source, `sample = 1 + drums·16384 + bank·128 + prog` (per-note regions). GSM samples: library source `gsm` (play decodes via engine, load copies into the instrument, dedup); instrument header "Import sample…" and sampler "Import WAV…" (browser decode → 44.1 kHz mono → `E.gsmEncode`, ≤ 30 s, size + clip report); "▶ Play", "Choose GSM sample…", "Remove unused" (drops unreferenced samples, renumbers slots). Group graphics follow their knobs: `redrawGroup` (rAF-coalesced) from knob change/automation `_set` and selects; `curVal` reads the knob value. `envView`/`envCurve` mirror unisynth env.rs (WaveSabre closed form, Tunefish per-512-block). Sampler: `samplerSettings` named controls (loop Off/Repeat/Ping-pong, region own/custom, interp, reverse), loop knobs only for a custom playing loop, normalised waveform with draggable start/loop edges/body (dragging the own loop makes it custom). Ctrl/Cmd+Z, Shift+Z, Y undo/redo anywhere outside text fields. Tunefish-mode envelope time knobs read `tfEnvSeconds` (attack 0→1, decay 1→sustain with current sustain/slope, release to −100 dB; "holds"/∞ when never ending); env group knob texts refresh with the curve (`_redrawText`). Track name tooltip = `aboutText(t.about)` (type · style · tempo · engine · like … — description). |
