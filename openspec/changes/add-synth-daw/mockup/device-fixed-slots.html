Unisynth kind 64 · preset init

• Osc / Filter: active = type ≠ Off. Choosing a type in a collapsed header expands it. ✕ resets the slot to Off in place (mod rows targeting it are cleared, its automation lanes removed) — later slots do not move.
• Filters run in series: ⇅ between two filters swaps them (mod targets and automation lanes follow). Other blocks have no reordering.
• Env / LFO have no type: "not set" = all defaults. The header shows what routes them (→ filt1.cutoff); knobs dim when nothing does. Env 1 is fixed (amplitude).
• Mod matrix: 12 fixed rows; source None = inactive (dimmed).
• Live (polyphonic): each sounding voice has one colour (chips in the title bar). Sampler: a playhead per voice. Env: a dot per voice on the curve + a level bar at the right edge. LFO: a dot per voice (each voice runs its own LFO). Filter: grey = input spectrum, block colour = output, ticks on top = each voice's modulated cutoff. Brightness follows the voice's amplitude; released voices are faded / dashed.
