# research/tbl-mini-cauldron/ref

Bit-exact Python references of mini-cauldron + decoded patch data. Run from this directory (`python3 mcauldron1.py patches_jizz.json <out>`). Python ≥ 3.13 (`math.fma`).

| File | Purpose |
|---|---|
| `golden_sha256.json` | SHA-256 of every raw render (`render_jizz/ProbeNV`, `render_stash/<song>_<slot>_<variant>`): golden vectors for a port, no audio needed. |
| `mcauldron1.py` | v1 (Jizz) reference: `Synth.render_patch`, `retrigger`, `frame`, `filt`, `echo`, `post`, `Rng`; persistent `buf`/`seg_reg`/`t`; writes `<ProbeNV>.s8` (raw int8, not delta) + `renders.json`. Verified 32/32 vs emulated XM. |
| `mcauldron2.py` | v2 (Stash) reference: `Synth.render_song` (two calls, shared buffer), waves 0–5 (4 = noise raises, unused), gate, `comb`, `doubler`, `post` (specials, decim, tail fade, in-place delta). Writes `<song>_<slot>_<variant>.s8`. Verified 53/53 + drums. |
| `patches_jizz.json` | 12 v1 records (A, B, decay, damp, wave, variants, mul, gain, echo, voices, pitch/accent/tie[16], raw hex), render `order`, `rng_state` at synth entry. Generated by `tools/extract_patches.py`. |
| `patches_stash.json` | Two v2 calls (bluish: 10 records/11 slots/6 drums/flag 0; song0: 16/17/7/flag 1), records incl. decim/comb/doubler/hold/release, drum lengths. Generated by `tools/extract_patches.py`. |
| `x87pc24.py` | x87 precision-control-24 arithmetic on f64: `add`/`sub`/`mul`/`div` (TwoSum / FMA TwoProduct, one 24-bit rounding, ties-even), `fistp`. |
