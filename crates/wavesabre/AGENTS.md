# crates/wavesabre

no_std f32 port of the WaveSabre devices (change add-wavesabre-rs). Upstream logicomacorp/WaveSabre @ 9245fb8, MIT (`LICENSE-WaveSabre`, keep the notice). Depends on `synth-core` (+`libm`). Each device = feature `ws-<name>` (default `ws-all`); every single-device build must compile warning-free. Behavioural reference = upstream source in the lab (`~/Downloads/64k-tools/synth-lab/WaveSabre`); reproduce upstream numerics (FastSin table, random law, op order), guard upstream UB. Toolchain: `PATH="$HOME/.cargo/bin:$PATH"`.

| `src/gsm.rs` | `GsmDecoder` (`new`, `decode_block(&[u8;65],&mut [i16;320])`) + `decode(data,&mut [f32])`: no_std GSM 06.10 decode-only, WAV49 framing, port of libgsm 1.0.24 (COPYRIGHT kept in header). Bit-exact i16 (saturating `add/sub`, `mult_r` rounding, arithmetic `>>`), 33+32-byte frames chained by `frame_index/frame_chain`. All bit patterns decode; `GsmError::Malformed` never returned (API stability). Trailing partial block ignored; out `pcm/32768` via f64. Feature `ws-specimen`/`ws-thunder`. Tests vs libgsm vectors. `GsmChunk` (WaveSabre sample chunk: `{comp,uncomp}` + WAVEFORMATEX(0x31 mono)+cbSize + blocks; `parse` (empty → `None`, bad sizes/format → `BadChunk`), length min(uncomp, blocks·320), `pool_need`, `decode` into pool, `rest` = trailing params). |
