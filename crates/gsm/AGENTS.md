# crates/gsm

no_std GSM 06.10 full-rate decoder (WAV49 / Microsoft framing), a bit-exact Rust port of libgsm 1.0.24 (decoder + WAV49 encoder), and the WaveSabre sample-chunk parser/header writer. Moved out of `crates/wavesabre` by change add-unified-synth so `wavesabre` and `unisynth` share one copy. Depends on `synth-core` only (`LoadError`, `Pool`). Toolchain: `PATH="$HOME/.cargo/bin:$PATH"`. Checks: `cargo check -p gsm --target i686-pc-windows-msvc -Zbuild-std=core`, `--target wasm32-unknown-unknown`.

| File | Purpose |

| `Cargo.toml` | Dep `synth-core`. |
| `src/encode.rs` | `GsmEncoder` (`new`, `encode_block(&[i16;320],&mut [u8;65])`) + `encode(&[f32],&mut [u8]) -> bytes` + `blocks_for(n)=ceil(n/320)`; re-exported at crate root. Port of libgsm `gsm_encode.c` (WAV49 pack: 1st frame 32 bytes + 4-bit `frame_chain`, 2nd 33; pack code mechanically generated from the C), `code.c`, `preprocess.c`, `lpc.c`, `short_term.c`, `long_term.c` (integer path, no FAST/USE_FLOAT_MUL/LTP_CUT), `rpe.c`, `add.c` (`norm`, `div`, `mult` non-rounding, `l_add`=`saturating_add`). Quirks matched: `mp` stays i32 (not word); `msp`/`lsp` word-truncated; autocorrelation scales `so` in place and rescales with `<<` (lossy, feeds the filter); `dpp` aliases `dp` slot in `dp0`; f32→i16 is `(x*32768) as i16` (trunc, saturating); last block zero-padded. Reuses root `add/sub/mult_r/asr/asl`, `QLB`, `FAC`. Debug build has no overflow panics on extreme input. |
| `src/lib.rs` | `GsmDecoder` (`new`, `decode_block(&[u8;65],&mut [i16;320])`) + `decode(data,&mut [f32])`: WAV49 33+32-byte frame chain, saturating `add/sub`, `mult_r` rounding, arithmetic `>>`; all bit patterns decode (`GsmError::Malformed` never returned, kept for API stability); out `pcm/32768` via f64; trailing partial block ignored. `BLOCK_BYTES` 65, `BLOCK_SAMPLES` 320. libgsm COPYRIGHT kept verbatim in the module doc. `GsmChunk` (WaveSabre sample chunk `{comp,uncomp}` + WAVEFORMATEX (tag 0x31, mono) + cbSize + blocks): `parse` (empty → `None`, bad sizes/format → `BadChunk`), `samples` = min(uncomp, blocks·320), `rest` = bytes after the compressed data, `pool_need`, `decode` into a `Pool`. `CHUNK_HEADER`=28 + `write_chunk_header(compressed,samples,&mut [u8;28])` = inverse of `parse` (cbSize 2, tag 0x31, 44100 Hz, avg 8957, align 65, extra 320); uncomp field = sample count so `parse` returns exact `samples` (real ACM files store bytes ≈ samples·2; parse then falls back to blocks·320). Tests vs libgsm vectors (decoder + encoder bit-exact, f32 path, round trip SNR, chunk header). |
