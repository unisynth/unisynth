# crates/unisynth

MIT no_std f32 unified synth (change add-unified-synth, in progress): one slot-based instrument (`synth-mix` kind 64) and one merged effect set (kinds 65–73) built from the WaveSabre and Tunefish algorithms; checked against the original engines in `synth-convert`'s tests (this crate does not depend on them). WaveSabre-derived code keeps the upstream notice (`crates/wavesabre/LICENSE-WaveSabre`). Depends on `synth-core`, `libm`, optional `gsm` (`us-sample-gsm`) and `dls` (`us-sample-dls`). Every module type is a cargo feature `us-*` (default `us-all`); a patch that needs a disabled module fails at load with `LoadError::UnsupportedModule(module id)`. Feature `std` = host-side only (chunk encoder, names, law inverses; never in the player). Toolchain: `PATH="$HOME/.cargo/bin:$PATH"`. Checks: `cargo check -p unisynth --target i686-pc-windows-msvc -Zbuild-std=core`, `--target wasm32-unknown-unknown`. Docs: `docs/synth/unisynth.md`; design: `openspec/changes/archive/2026-10-26-add-unified-synth/design.md`.
