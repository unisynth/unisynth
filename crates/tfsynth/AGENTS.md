# crates/tfsynth

MIT `no_std` f32 synth engine sound-compatible with Tunefish 4 (change add-tf-synth). Own implementation from
`research/tunefish4-functional-spec.md`; upstream GPL source read for behaviour only — no copied code, comments,
tables or identifiers. 44 100 Hz, 512-frame blocks, no heap, no `core::fmt`. Builds on `synth-core` (Freeverb
comb/allpass, `Ring`, DF1 `Biquad`, `OnePole`, `Pool`, `VoicePool` with `Steal::Oldest`, `Device`). Features
`tf-fx-<kind>` (distortion, delay, chorus, flanger, reverb, formant, eq), default `tf-fx-all`. Toolchain:
`PATH="$HOME/.cargo/bin:$PATH"`. Checks: `cargo check -p tfsynth --target i686-pc-windows-msvc -Zbuild-std=core`,
`--target wasm32-unknown-unknown`.
