# crates

Rust workspace members. Player-path crates are `no_std` (`#![cfg_attr(not(test), no_std)]`). See `docs/synth/README.md`. Use rustup nightly cargo (`PATH="$HOME/.cargo/bin:$PATH"`).

| Crate | Purpose |
|---|---|
| (external) `dls`, `gmgen`, `gmfit` | Moved to https://github.com/unisynth/gm-procedural (DLS reader/writer, procedural GM bank, fitter, assets, A/B pages, docs). Consumed here as `[workspace.dependencies]` git deps pinned by `rev`; local co-dev: `[patch."https://github.com/unisynth/gm-procedural"]` path override in `.cargo/config.toml`. |
| `glorp/` | MIT no_std f32 independent implementation of the Glorp song device set (written from observed behaviour, no original code/data in git). Devices ID 3, 7, 14, 20, 21, 22, 25, 27, 28, 30, 32, 34, 35, 38 (subsets where noted), instruments on a shared 16-voice scheduler (`synth::Synth`). Wired into `synth-core` `Player` as `kinds::GlorpDevice` behind `preflight::preflight` (refuses unsupported ids / chunks / settings / rates / unsafe automation before a device exists); owned `player::GlorpPlayer` with full `Reject` diagnostics. 44.1 kHz, sub-block 128. The real song is accepted and plays (tolerance parity of the mix vs the original 16-bit render). No `synth-mix` kind id (ids 3 / 7 clash with WaveSabre: never in an `Either` with `WsDevice`). Parity tests need `GLORP_REF_ROOT`. → see `glorp/AGENTS.md`, `docs/synth/glorp.md`. |
| `gsm/` | no_std GSM 06.10 (WAV49) codec, bit-exact libgsm 1.0.24 port: decoder (`GsmDecoder`, `decode`), encoder (`GsmEncoder`, `encode`, `blocks_for`), `write_chunk_header`; libgsm COPYRIGHT kept in `src/lib.rs`. `GsmChunk`: WaveSabre sample chunk parser (`parse`, `pool_need`, `decode` into pool, `rest`). Used by `wavesabre` (`ws-specimen`/`ws-thunder`, re-exported `wavesabre::gsm`) and `unisynth` (`us-sample-gsm`). `testdata/`: libgsm vectors. → see `gsm/AGENTS.md`. See change: add-unified-synth. |
| `song/` | std host-only `song/2` source + `us-patch/2` presets for the unified synth (`song/1` migrated on parse; in default-members): serde model, validation → JSON-pointer `Issue`s, export / import of the `synth-mix` blob (import cuts lanes into patterns), parameter tables, render through `Player<UDevice, Xorshift(1)>`, bin `song export|import|render|info|check|migrate`; `--bank plus` = `gmgen::plus::build`, else a path / `GM_DLS`. → see `song/AGENTS.md`. See change: add-synth-daw, unify-v2-algorithms. |
| `synth-convert/` | std host-only converter (not in default-members): legacy WaveSabre / Tunefish `synth-mix` songs, `.tfm`, `.tf4m`, Farbrausch `.v2m`, Tunefish patches and mini-cauldron XMs → unified songs (kinds 64–73); also `migrate` (old layout → v3), `features`, `rust` (compo build). Parity tests vs the legacy engines. → see `synth-convert/AGENTS.md`. |
| `synth-core/` | no_std f32 shared synth layer (change add-wavesabre-rs): Freeverb `Comb`/`AllPass`, `Ring` delay, DF1 `Biquad`+RBJ `Coefs`, `OnePole`, libm `math`, `denormal::Guard`, bump `Pool`, `Rng` trait, `Device` trait + `Events`, `VoicePool`, `mix` (`Song` WaveSabre-blob decoder, `Kinds` registry trait, `Player`, `LoadError` incl. `UnsupportedModule`). → see `synth-core/AGENTS.md`. |
| `synth-wasm/` | std cdylib+rlib DAW engine module (not in default-members): live `Host` (player `Mixer` over an editable schedule; bit-identical to `Player` from frame 0; D4 edit diff; transport loop/chase; audition; meters; no allocation in `render`), `song` functions, stepped bounce for the bounce Worker (`bounce_open`/`bounce_step`/`bounce_left`, threaded variant in `par.rs`); plain C ABI. → see `synth-wasm/AGENTS.md`. See change: add-synth-daw, add-wasm-threads. |
| `tfsynth/` | MIT no_std Tunefish-4-compatible synth (change add-tf-synth): 112-param patches, spectral IFFT generator, filters, ADSR/LFO, mod matrix, 10 insert effects (`tf-fx-*` features), `.tfm` player, `Device` kinds 32–39 on `synth-core`. → see `tfsynth/AGENTS.md`. |
| `unisynth/` | MIT no_std unified synth: one slot-based instrument (kind 64) + merged effects (kinds 65–73) holding WaveSabre, Tunefish, V2 and mini-cauldron algorithms as modules / modes. v3 layout (294 values), chunk v3 (v4 = + speech); voice framework, oscillators (phase-mod, saw/pulse, wavetable, sampler incl. GSM / DLS, clocked), noise, filters, envelopes, LFOs, mod matrix, channel strip; every module a feature `us-*`. → see `unisynth/AGENTS.md`. See change: add-unified-synth, unify-v2-algorithms. |
| `wavesabre/` | no_std port of all 13 WaveSabre devices (kinds 0–12, feature `ws-<name>` each) + QM fork device Screwdriver (kind 13, `ws-screwdriver`); upstream MIT notice kept. `WsDevice` registry enum on `synth-core`; helpers (FastSin table, `WsRng`, curves); instruments Falcon / Slaughter / Thunder / Specimen / Adultery (shared `synth` + `sampler`, `gsm`, GM.DLS via `dls`); effects Scissor / Leveller / Crusher / Echo / Smasher / Chamber / Twister / Cathedral; self-golden tests. → see `wavesabre/AGENTS.md`. See change: add-wavesabre-rs. |
