# crates/synth-convert

Host-only (std) converter from legacy songs to unified songs (change add-unified-synth). Never linked into the player,
not in the workspace `default-members`. Library `synth_convert` + bin `synth-convert`. Commands: `ws`, `tfm`, `tf4m`, `e3prj`, `tf3`, `elevated`,
`tf4m-tfm`, `v2m`, `patch`, `xm`, `xm-phrase`, `xm-triggers`, `migrate`, `features`, `rust` (full list in `src/main.rs.AGENTS.md`).

```text
synth-convert ws    <in.song> <out.song>                 legacy synth-mix song (kinds 0–12, 32–39) → unified song (64–73)
synth-convert tfm   <in.tfm> <out.song> [tail-s]         .tfm song → unified song (tracks, inserts, master)
synth-convert patch <patch.txt> <phrase.txt> <out.song>  one Tunefish patch (112 numbers) + `block note velocity` lines
synth-convert features <unified.song>                    the unisynth cargo features it needs, comma separated
synth-convert e3prj <in.e3prj> <out.song> [--song id] [--editor | --engine 2011] [tail-s]   Tunefish 3 project → unified song
synth-convert tf3   <program.txt> <out.chunk> [--editor]  one Tunefish 3 preset → unified instrument chunk
```

Any problem prints a message to stderr, exits non-zero and writes no output; warnings do not stop the conversion.
Conversion rules, error list and walkthrough: `RULES.AGENTS.md` (pull-only).
