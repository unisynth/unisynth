# src/id25.rs (sidecar: full detail of the AGENTS.md row)

Pull-only (not auto-injected).

- `Id25::new(&[f32;15])`, `set_param(i, v)` (atomic: `Err(Index)` i ≥ 15, `Err(Range)` non-finite / outside [0,1]), `note_on(note, offset)` / `note_off(note, offset)` (`Err(Note)` > 127, `Err(Offset)` > `i32::MAX`, `Err(QueueFull)` at 256 queued), `process(l, r)` **overwrites** (instrument; equal lengths, panics otherwise), `active_voices()`, `voice_notes()`.
- Percussion synth, pitch-independent (note only seeds the filter randomisation, velocity does not exist): exponential-sweep sine body phase-modulated by lowpassed hashed noise + detuned sine layer, 5 cascaded biquads, soft limiter, ADSR (A 0.001, D 0.5, S 0, R 0.5 s, so a note lives until note-off + release); params re-read per sample; P1/P4/P8 stored but unread.
- Shared scheduler in `synth.rs`; `expf`/`sinf`/`cosf`/`sine_table`/`hash`/`Rng`/`Biquad`/`DT`/`W_RBJ`/`P31`/`P32` are `pub(crate)` and reused by `id27`.
- Math: `expf`/`2^e`/`sinf`/`cosf` are f64 `libm` `exp`/`exp2`/`sin`/`cos` rounded to f32, an ordinary approximation (no msvcrt / musl / ARM tables or coefficients: provenance could not be shown independent, see research doc §ID 25 "exponential provenance"); sine table = `id34`'s with node 305 patched; limiter `powf(u,2)` = `u·u` (original 1 ulp high on 0.07 %).
- Song device 8: 93.13 % of 20.04 M samples exact, max error 6.857e-4 at peak 5.30; 44 vectors: 29 ≤ 4.8e-7, worst 1.227e-2 at peak 7.4 (`s00lo`) — **tolerance parity** (fixture bound `2.5e-3·peak`), not bit parity.
- See `research/glorp-devices.md` §ID 25.
- Not modelled: mono/legato, unison, other sample rates.
- **Standalone poly-only API: cannot accept mono/unison and cannot detect them.** The adapter cannot detect them either: the song chunk has no field for them, so `preflight` refuses any chunk that is not exactly 15 params + size (a voice-mode extension would be longer).
- `check(p)` = what `new` accepts (cheap).
