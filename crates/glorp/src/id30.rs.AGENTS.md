# src/id30.rs (sidecar: full detail of the AGENTS.md row)

Pull-only (not auto-injected). Independent behavioural ID 30 implementation; no original code, table or tap.

- API: `Id30::new(&[f32; 24], &mut Pool<'a>) -> Result<Id30<'a>, Error>`; `Error::{Index, Range, Topology, Memory}`;
  `set_param(i, v)` atomic, judged on the whole resulting vector (`check`); `process(l, r)` in place, equal lengths
  (panics otherwise), params read once per call; `reset()` clears lines, filters, shifter, RNG seed in place; `check(&p)`;
  consts `PARAMS` = 24, `SLAB_F32` = 1,015,584 floats (≈ 4.06 MB), `MAX_STREAMS` = 5.
- Model: smoothed stereo delay line 176,400 samples (glide `+= (target − t)·0.021` per write), 50 % overlap-add grain
  engine (`trunc(5·P8)` streams, two slots each, pitch `2^(2·P7−1)`, hash scatter `P9·P0·22050`, sine-table envelope,
  `1/N` average, 0 streams = plain tap), Freeverb-style reverb (8 combs 1116…1617, 4 all-passes 556/441/341/225, right side
  +23, gain 6, feedback `min(0.999, P12)^0.2`, freeze), RBJ LP/HP (Q 0.7), ID 34-style shifter on the feedback path,
  128-stage delay-line all-pass cascade (P16 > 0.001). Parameter table: module docs of `id30.rs`.
- Invariants: f32 scalar operation order of the reference (no FMA) because order decides bit parity; reverb lines keep the
  original's 44,100-entry index bookkeeping over 2,048-sample rings (`REV_CAP`); **topologies 1 / 2 refused** while the
  cascade is on (`Error::Topology`), the song uses topology 0 only; `P10 = 0` is safe (window sine of 0/0 stays finite and
  silent; nothing read out of range); `P23 < 0.5` leaves the block untouched and freezes all state.
- Math: f64 `libm` `exp2`/`pow` rounded to f32, shared `id25::{hash, sine_table, Biquad}`, `id27::rbj_pass`,
  `id34::{tick, sin_with, CHAIN_A, CHAIN_B}`. Measured deviations from the original on the song: device 19 max 2.5e-13
  (1.5e-13 of peak, 75.4 % exact; cause not investigated) and device 20 max 1.414e-4 (9.6e-5 of peak; probably a 1-ulp filter
  coefficient from `libm` trig, not proven); devices 15 / 16 / 17 / 21 bit-exact, 18 inactive. See `research/glorp-devices.md` §ID 30.
- Non-finite input: `process` does not sanitise samples. A NaN / inf input sample enters the delay line, filters, reverb and
  feedback path and can poison that state (long delay / reverb tails) until `reset`; characterised by
  `a_nan_input_sample_poisons_the_state_until_reset`. **Original behaviour on NaN input is not reference-verified** (no
  recorded non-finite input; the 82 vectors and 7 taps are finite). Params are rejected when non-finite, input is not.
- Attribution: whole-song residual vs `fullA.wav` (60.397 % exact, worst 136 steps, upstream `pcm_i16` conversion) is carried by
  ID 35 device 27: oracle replacement drops worst 136 → 10 PCM steps. ID 30 devices are exact / near-exact given the recorded
  input, so they only pass input error on; the remaining devices are not isolated.
- Player: `kinds.rs` builds it pool-first (`Shell::in_pool`, `Kinds::need` = shell + `SLAB_F32`), `preflight.rs` judges the
  cascade topology on the box corner (P16 and P20 at their tops).
- Tests: `src/tests30.rs` (synthetic, 18 incl. the NaN-input characterisation), `tests/reference30.rs` (env-gated), `tests/reference_player.rs` (adapter + whole song).
