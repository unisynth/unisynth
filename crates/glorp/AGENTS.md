# crates/glorp

MIT `no_std` f32 devices matching the proprietary Glorp song's device set: an independent behavioural implementation from observed behaviour (`research/glorp-devices.md`); no original binary, pseudocode, song, dump, tap or proprietary vector in git. Kinds 3, 7, 14, 20, 21, 22, 25, 27, 28, 30, 32, 34, 35, 38 (limits in the rows) on a shared 16-voice scheduler (`synth`). `kinds::GlorpDevice` plugs into `synth_core::mix::Player` behind `preflight::preflight`; `player::GlorpPlayer` is the owned API. Every unsupported id / chunk / setting / rate / block size / automation lane is refused before a device exists. Sub-block 128 and 44.1 kHz only; unison cannot be represented. The real song is accepted and plays (`docs/synth/glorp.md`). Never put `GlorpDevice` in an `Either` with `WsDevice` (overlapping kind ids). In root `default-members`.

`cargo test -p glorp` skips reference parity (passes vacuously without `GLORP_REF_ROOT`). Fixtures, runtimes, extra checks: `TESTING.AGENTS.md`. Architecture detail: `OVERVIEW.AGENTS.md`.
