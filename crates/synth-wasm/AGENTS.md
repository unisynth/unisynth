# crates/synth-wasm

std cdylib + rlib (change add-synth-daw, spec synth-live-host; not in default-members): the DAW engine module. Live `Host` = `synth_core::mix::Mixer` over an editable source, built from the exported blob with the player's device load order and `Xorshift::new(song::render::SEED)` → bit-identical to `Player` from frame 0 without edits (any call size; also wasm32 vs native, checked on the demo song). Plus `song` crate functions behind the C ABI. Build: `cargo build -p synth-wasm --release --target wasm32-unknown-unknown` → `target/wasm32-unknown-unknown/release/synth_wasm.wasm` (~500 KB; one import `env.host_now_ms() -> f64`). Toolchain `PATH="$HOME/.cargo/bin:$PATH"`.

| `src/host.rs` | `Host`: `load(blob)` (devices in song order from the song rng; one `Slot` per device = device + own arena + chunk, drop order safe), `update(blob)` → `Edit { params, rebuilt, schedules, mixer, reload }` (D4 diff per track: chunk value-only change → `set_param`, structural/sample/kind/mode/length → rebuild chain from `host_rng`, lane/automation change → schedule swap with note-off of open notes + cursor after next sub-block + the track's event lookahead (already delivered), receives → mixer rebuild, track count/rate/tempo → reload keeping transport), `render(frames ≤ MAX_FRAMES 4096)` → owned interleaved f32 (no allocation: tested with a counting allocator), `play(frame)` / `seek` (devices reset, mixer reset at frame, held notes chased, autos seek; no pre-roll), `stop` (notes off, tails ring ≤ 2 s; stop again = silence), `set_loop([a, b))` (sub-block capped at `b`, events ≥ `b` held back, wrap = seek with chase at the end sample), `note_on/off` (audition queue per track, before chase and schedule; playing or stopped), `set_param(track, device, param, v)`, `peaks()` per track + master (blocks a call touches), `load_ratio()`, `position()`, `set_bank`. `Auto` = player's automation walk over owned points (bit-identical). `Sched`/`TrackView` implement `Source`/`TrackSource`. `voice_counts()` → sounding voices per device slot (diagnostics; allocates). Silenced while stopped: `load_ratio` 0. |
| `src/lib.rs` | C ABI (static `HOST`, `OUT`): `alloc/dealloc/out_ptr/out_len`; host `set_bank/load/update/render/play/stop/seek/set_loop/position/is_playing/note_on/note_off/set_param/peaks_ptr/peaks_len/load_ratio`; song `song_tables` (`tables_json`), `song_physical`, `song_validate`, `song_export` (1 = blob in OUT, 0 = issues JSON), `song_import`, `preset_save` (`{device, name}`), `preset_load`; bounce `bounce(blob) → frames` + `bounce_ptr` (= `song::render::render`, the exact intro sound, D7). `gsm_chunk_decode(chunk)` → f32 PCM; `gsm_chunk_encode(pcm)` → GSM sample chunk (header + WAV49 blocks, `gsm::encode`); C ABI `gsm_decode(p,n)` (OUT f32 LE) and `gsm_encode(p,n)` (n f32 LE at any alignment → OUT chunk). |
