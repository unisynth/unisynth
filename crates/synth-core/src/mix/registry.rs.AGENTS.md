# src/mix/registry.rs (sidecar: full detail of the AGENTS.md row)

Pull-only (not auto-injected). Device kind registry: synth-core cannot depend on engines, so each engine (or a facade) supplies an enum of its enabled kinds implementing `Kinds` + `Device`; dispatch is a `match`, no vtables; disabled features have no variant.

- `Env{rate, tempo, bank: Option<&[u8]>}` (`Env::for_song(song, bank)`; bank = DLS bytes, bankless devices play silence).
- `Kinds<'a>: Device + Sized`: `need(kind, chunk, env)` (pool bytes upper bound; unknown/disabled → `UnsupportedKind`), `load(kind, chunk, env, pool, rng)` (load-time draws from the song rng, song device order), `block(song, env) -> Result<Option<usize>, LoadError>` (default `Ok(None)`: the only sub-block the registry's devices are valid at for this song; `Some` only when the song holds one of its devices; `Player::new` refuses another `sub` with `Malformed`), `preflight(song, env)` (default `Ok`: whole-song check run first by `load_devices`, before any kind resolves or device builds, so `Player::new` cannot skip it; for engines whose `set_param` cannot report a refusal; judge only own kinds).
- Feature `threads`: `Kinds::RENDER_RNG` (default true = draws from `Ctx::rng` while rendering → serial only).
- `devices_need::<K>(song, env)`, `load_devices::<K>(song, env, pool, rng)` (preflight → kinds checked → built in pool via `uninit`, song order).
- `Either<A, B>` facade for mixed-engine songs: `Kinds` tries A, falls back to B on `UnsupportedKind` only (`UnsupportedModule` does not fall back). Registries must own disjoint kind numbers (both preflights see the whole song; overlap unsupported). `block`: one owner decides, two owners must agree else `Malformed`. `RENDER_RNG` = A ∨ B. `Device` forwards `param_count`, `lane_lerp` (without it a Glorp device in an `Either` plays in the default form: silent wrong sound; pinned by `glorp/src/tests_kinds.rs::glorp_lanes_use_the_original_form_alone_and_inside_an_either`), `set_param`, notes, `all_notes_off`, `event_lookahead`, `quiet_after`, `quiet_skip`, `wake`, `reset`, `run`. Does not forward `automation()` (default `Ok`) nor `run_ext` (default → `run`).
