# src/mix/mixer.rs (sidecar: full detail of the AGENTS.md row)

Pull-only (not auto-injected). Shared per-sub-block track step (design D3), used by `Player` and the DAW live host.

- `Source` (`track_count`, `track(t) -> TrackSource`; `track` must not change state, the mixer also calls it to read routing). `TrackSource`: `devices()` (song-level indices, chain order), `receives()`, `volume()`, `peek()`/`advance()` events in absolute frames, `automate(n, set)`.
- `Mixer<'a>` (pool, no heap): `need(tracks, sub)`, `check(src, n_devices)` (≥ 1 track, device and receive ranges, receive from another track, channel 0|2, with `pairs` a valid `recv` field; non-blob sources call it before `new`), `new(src, pool, sub)` (upstream pass order, cycle → `BadIndex`; assumes a checked source), `update_look(devices, src)` (track lookahead = max device L), `sub()`, `frame()`, `reset(frame)`, `set_skip_quiet(on)`, `render_sub(devices, src, rate, tempo, rng)`, `channel(t, ch)`, `master_frame(i)` (last track main L/R).
- Step per track in dependency order: events (frame < t0+n+look) → clear + receives → sleep/wake decision → automations → devices in chain order (each followed by `denormal::flush_io`, wasm only) → volume. Automation walk runs only when the first device's `automation()` is `Ok`.
- `render_sub` is `#[inline(never)]`: keeps the WaveSabre size probe at pre-split size (`ws-size-probe` slaughter 25 710 → 25 522 B `.text`); unified probes +272 B demo song / +2.9 KB all modules; no measurable speed cost.
- Quiet skip: `may_sleep` (no event due ≥ t0 via `Bufs::due`, zero input, `Bufs::quiet` ≥ max(`chain_quiet`, `QUIET_MIN` 4096)); `chain_quiet` = sum of device `quiet_after`, `None` if one is unknown or its `quiet_skip()` is false; `loud` (any device's output or the input ≥ `QUIET_LEVEL` 1e-6) resets the quiet run (`note_quiet`); `Bufs::asleep` frames → `Device::wake` before the next run; `still_asleep` runs a track whose automation made a device's memory unknown; `set_skip_quiet` (default on, effective only with `quiet_skip()`) clears quiet runs on a switch; wake follows capability, not the switch.
- Feature `pairs`: `Bufs.ext` per track (`EXT_CH` buffers, cleared each sub-block), `run_ext` instead of `run`, `add_receive` from sender pair to receiving pair, `scale` also covers the output pairs; same in `par.rs`. `Mixer::need` counts 4 + `EXT_CH` buffers per track.
- Feature `threads`: field `levels` (`par::Levels`), `need` += `Levels::need`, `mod par`, re-exports `Par`, `SplitSource`.
