# src/tests.rs (sidecar: full detail of the AGENTS.md row)

Pull-only (not auto-injected). Unit tests of the whole crate (`#[cfg(test)] mod tests`). Run: `cargo test -p synth-core` (+ `--features threads`, `--features pairs`).

- Top level: maths (`note_to_hz` points, dB/gain round trip, equal-power pan, `clamp`/`mix`/`exp2`); `lerp_is_a_plus_delta_t_and_stays_inside_the_segment` (exact op order, ≠ `mix` in a minority of inputs, ≤ 2 ε outside the segment over spans 1…i32::MAX); pool (alignment, zeroing, overflow, `need` upper bound); denormal guard restores mode; comb / allpass / ring / biquad / one-pole.
- `device_tests`: event offsets, offset 0 / == n, lookahead carry, call-split independence, slot order, full array drop, reset.
- `voice_tests`: no-steal drop, oldest steal + ties, limit, note-off match, unison spread, mono legato + guards, mode change kills voices.
- `blob` test writer; `mix_song_tests`: round trip, truncation at every byte, trailing bytes, bad refs, huge counts, unsupported kind, kinds load in song order; env-gated `real_songs_parse` / `real_songs_load_and_render` (`WS_SONG_DIR`, 52 upstream refs converted in the lab; skipped when unset).
- `player_tests`: `owned_source_renders_like_the_player` (`VecSource` == `Player`), `mixer_check_rejects_bad_routing`, sidechain send, `extra_pairs_carry_sends_and_aux_inputs` (feature `pairs`), dependency order, cycle, param OOR, automation lerp + negative times, caller-size independence, seek, lookahead (kind 3 recorder L 511 → call 500 offset 523), volume + i16, length. Feature `threads` `par`: `PD` device (TD without render draws + kind 4 subnormal-decay tone), `Serial` / `Threads(w)` `Par`, levels, fallback (render-rng kind, shared device), owned `VecSource` split, workers 1/2/3/8 × calls 1/77/100/4096, seek, i16, worker flush.
- `either_tests`: dispatch by kind + forwarding (lookahead), `UnsupportedModule` is not a missing kind (no fallback).
- `lane_lerp_tests`: recording `Rec` devices; `Either<Mix, Delta>` over two tracks / four devices / several lanes per device, each lane bit-equal to its device's form, seek keeps it, registries swapped, default = `Mix`; feature `threads`: parallel walk same forms.
- `hook_tests`: build counter `BUILT` is `thread_local` (libtest runs siblings concurrently; a shared atomic made the preflight test flaky ~1 %; pinned by `build_counter_ignores_builds_on_other_threads`); `Kinds::preflight` runs before any device is built, `Player::new` cannot skip it, wrong `sub` refused, defaults inert, `Either` forwards the preflight; per-song block: foreign-only song not pinned in both orders, owned / mixed pinned, conflicting owners refused, agreeing accepted.
- `quiet_skip_tests`: skipped tracks sound the same (tone → echo tail kept), unknown-memory devices keep their track awake, receive input wakes a sleeping track, `wake` comes once before the waking block's automation with the frames slept, switching skip mid-song keeps output, automation that makes a track audible wakes it, early-delivered note keeps its track awake until due, a device that refuses the skip keeps its track awake.
