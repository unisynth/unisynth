# crates/synth-core

no_std, f32, no heap (change add-wavesabre-rs). Shared synth layer for all engines (WaveSabre port, Tunefish-compatible `tfsynth`): primitives that are the same algorithm in several engines + the device/mixer framework (`Device`, `VoicePool`, `mix::Player` on the WaveSabre song blob). Only dep `libm`. In root `default-members`. Rule (design D2): a primitive lives here only if ≥ 2 engines use the same algorithm; engine-specific numerics (WaveSabre FastSin table / `exp2(db/6)` dB, Tunefish IFFT/ladder) stay in the engine crate. Toolchain: `PATH="$HOME/.cargo/bin:$PATH"`. Checks: `cargo check -p synth-core --target i686-pc-windows-msvc -Zbuild-std=core`, `--target wasm32-unknown-unknown`.
