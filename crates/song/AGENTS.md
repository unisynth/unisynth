# crates/song

std host-only `song/1` song source and `us-patch/1` presets for the unified synth (change add-synth-daw, spec song-source). Shared by the `song` CLI and (task group 3) the browser live host `crates/synth-wasm`, so the browser saves exactly what the CLI writes (design D2). Deps: `serde`, `serde_json` (`preserve_order`: stable key order in saved files), `serde_path_to_error`, `synth-core`, `unisynth` (`std`: chunk encoder, host names/laws). Schemas: `schema/song.schema.json`, `schema/us-patch.schema.json`. Example: `project/music/demo.song.json`.

| File | Purpose |
|---|---|

| `src/export.rs` | `tick_to_sample` = `round(tick·60·rate/(tempo·960))`, `sample_to_tick` (exact f64), `chunk(device)` (kind 64 canonical chunk v1; effects `[mode, every param]` + trailer = byte size or the imported one), `flatten(song, track)` (placements sorted, loops repeat every clip length, cut at placement end), `events` (one open note per pitch: earlier cut at next start, superseded dropped, off ≥ on+1; same sample: offs then ons, pitch order), `export`/`export_model` (validate first; tracks then master; bypassed devices + their lanes left out; muted = volume 0 + no events; blob tempo = round(tempo); header length = (frames+0.5)/rate). Overflow-safe (saturating) on hostile ticks. Kind 64 writes `chunk::encode_text` with `speech` joined by NUL (version 2 only when non-empty). See change: add-v2-import. `controller(song, track, pick, rest)`: a clip `wheel`/`bend` envelope per placement and loop pass (start/end values, stable step order) back to `rest` at the placement end; `export_model` adds it as `ctl.wheel`/`ctl.bend` automation of the first unbypassed instrument (task 2.5a). Receives write `recv::encode(send, channel.to())`. |
| `src/import.rs` | `import` = `import_one_clip` + `patterns::split` (default; spec "Import from the song blob" modified by add-import-patterns). `import_one_clip` blob → song: kinds ≤ 39 → "kind N is a legacy device; convert the song with synth-convert first"; kind 64 via `Chunk::parse` (non-default values by name, samples base64); effects positional → names, `trailer` kept when non-canonical; one clip per lane (`laneN`, shared lane = linked placements) at tick 0, notes rounded to ticks (open notes end at song end); automation ticks fractional (exact samples), value byte/255; ids `t1…`, `master`. Never panics on a blob that parses (fuzzed). `apply_meta(song, text)`: import config = `Meta` fields + optional `about` + `tracks: [{name, about?}]` (count = tracks before master, else error, song unchanged). See change: add-import-patterns. Released-intro tolerance: automation after the blob end is cut at the end with the interpolated value (no song stretch); point ticks made monotonic and ≥ 0; velocity clamped 1..=127; values within 1e-6 outside 0..1 snapped (`unit_snap`). Reads chunk text back into `Device.speech` (split on NUL). See change: add-v2-import. `notes`: a note ended at the sample where another started just before it (on, then off: a mono legato, the clocked's tied phrases) lasts one tick longer, so the export (offs first at one sample) plays the new note first again. See change: add-tbl-demo-songs. Receives keep the blob channel field: `recv::to` → `Channel`, `recv::from` → `send` (V2 reverb/delay sends, aux inputs were lost before as main). |
| `src/lib.rs` | `Issue { path (JSON pointer), message }`, `parse` (serde_path_to_error → JSON pointer built from path segments, so dotted parameter names stay one segment; unknown field → its object), `load` (parse + validate), `to_json`/`pretty` (2-space, scalar arrays on one line), `features(song)` (conservative `us-*` list from values; add-unified-synth 6.4 is the reference once it lands). `workers` module behind feature `threads`. |
| `src/main.rs` | CLI `song export\|import\|render\|info\|check` (`-o`, `--f32`, `--bank` or `GM_DLS`); `song`/`help`/`--help` print usage (exit 0 for help, 2 otherwise); empty `GM_DLS` = no bank; errors `file: /pointer: reason`, exit 1, atomic write (tmp + rename), nothing written on failure. `import --meta <meta.json>` attaches and validates authorship (issues printed with the meta path, nothing written); `info` prints title/author/copyright/url, `adapted from …` and the description. `import` cuts lanes into patterns unless `--one-clip`; `--meta` goes through `apply_meta` (track names, `about`); `info` prints the song `about` (type; style; tempo) and `[role]` per track. | `src/model.rs` | `Song { format "song/1", rate, tempo f64, signature, ticks_per_beat 960, length ticks, clips, tracks, master }`, `Clip { id, length, notes, wheel?, bend? }`, `Note` = `[start, len, pitch, vel]`, `Point` = `[tick, value]` (whole ticks written as integers), `Track { id, name, color?, volume (linear), mute, receives, devices, placements, lanes }`, `Receive { from, channel main\|side, volume }`, `Device { kind, values, samples?, bypass?, preset?, trailer? }`, `Placement { clip, start, length (null = clip length), loop }`, `Lane { device, param, points }`, `Values` (ordered name → f32 map, duplicate key rejected). All `deny_unknown_fields`. `Song.meta: Option<Meta>` (written right after `format`, skipped when absent): `Meta { title?, author, description, copyright, license?, url, adapted_from? }`; not in the blob. `About { type, style?, tempo?, engine?, similar_to, description }` (`deny_unknown_fields`) as `Song.about` (after `meta`) and `Track.about` (after `name`); not in the blob. See change: add-import-patterns. `Device.speech: Vec<String>` (kind 64 Ronan texts, skipped when empty). See change: add-v2-import. `current_name(n)`: old unified-synth names → current (via `unisynth::params::rename::OLD`), applied to `Values` keys and `Lane.param` on read. See change: unify-v2-algorithms 1.3. `Receive.send` (0 omitted = main output, 1–4 extra output pair) and `Channel::{In1,In2}` (extra input pairs); `Channel::to/of` ↔ blob receive byte 0. |
| `src/patterns.rs` | Pattern detection for import (design P1–P4 of add-import-patterns): `split(song)` per one-clip lane → `GRIDS` 8/4/2 bars, `plan`: cut points = grid lines no note strictly crosses (segments grow), identical segment = same clip, variant = ≥ ½ notes of the larger matched (pitch, start ± bar/64) vs an earlier base of the same length → `<base>.<n>`, else next `letters(i)` (`A`…`Z`, `AA`); back-to-back repeat of a whole-length clip → one looping placement; last placement cut at the song length; cost = distinct notes + `PLACEMENT_COST` 8 per placement, least wins (ties → longer grid). Clip ids `<first track id>/<name>`; every track playing the lane gets the same placements. Skips clips with wheel/bend and songs over `MAX_WINDOWS` 2-bar windows (hostile lengths). Notes never move in absolute time → export unchanged. |
| `src/preset.rs` | `us-patch/1` `Preset { format, name, kind, values, samples? }`: `save` (non-default values sorted by param index; effect `mode` always kept), `load` (fresh device, others default), `parse` (validated names/ranges), `to_json`. |
| `src/render.rs` | `render(blob, bank)` → whole-song interleaved f32 through `Player<UDevice, Xorshift::new(SEED=1)>` (CLI and DAW bounce), `wav(samples, rate, float)` (16-bit = player's `clamp(trunc(x·32767))`, or f32). `render_threads(blob, bank, n)` (feature `threads`): `Player::render_f32_par` on `workers::with_workers(n)`, n ≤ 1 = `render`; bit-identical. See change: add-synth-threads. |

See change: unify-v2-algorithms 1.3. Mini-cauldron modes: Distortion Wrap (`drive` 0.25 = ×1, `offset` 0.5 = 0), Flanger Comb (`delay`, `amount`, `sweep`, `restart`; defaults pass through). See change: add-tbl-demo-songs. Osc type options name the clocked kind (`Clocked`, stored position 3). See change: add-tbl-demo-songs. |
