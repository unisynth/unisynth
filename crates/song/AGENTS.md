# crates/song

std host-only `song/2` song source and `us-patch/2` presets for the unified synth (change add-synth-daw, spec song-source). Shared by the `song` CLI and the browser live host `crates/synth-wasm`, so the browser saves exactly what the CLI writes. Deps: `serde`, `serde_json` (`preserve_order`: stable key order; `float_roundtrip`: fractional ticks load and save exactly), `serde_path_to_error`, `synth-core`, `unisynth` (`std`), `gmgen` (`plus`: `--bank plus`). Schemas: `schema/song.schema.json`, `schema/us-patch.schema.json` (repo root). Example: `project/music/demo.song.json`. Per-file detail beyond a row sits in pull-only `<file>.AGENTS.md` sidecars.

| File | Purpose |
|---|---|
| `Cargo.toml` | Lib `song` + bin `song`. Feature `threads` (default on; → `synth-core/threads`, `unisynth/threads`): `workers`, `render_threads`, `render --threads`. See change: add-synth-threads. |
| `src/b64.rs` | Padded RFC 4648 base64 `encode`/`decode` (GSM sample entries in device values). |
| `src/blob.rs` | Owned `synth-mix` blob `BlobM { tempo, rate, length s, devices (kind, chunk), lanes (abs sample, EventKind), tracks: TrackM { volume, receives (track, ch, vol), devices, lane, autos: AutoM { device, param, points (abs sample, byte) } } }`: `read` (validated by `synth_core::mix::Song::parse`), `write` (delta-encodes). |
| `src/export.rs` | Song → blob, deterministic. `tick_to_sample`, `sample_to_tick`, `chunk(device)`, `flatten`, `controller` (clip wheel/bend → `ctl.*` automation), `export`, `export_model` (→ `BlobM`; validates first). Muted = volume 0 + no events; bypassed devices and their lanes left out. → see `src/export.rs.AGENTS.md`. |
| `src/import.rs` | Blob → song. `import` = `import_one_clip` + `patterns::split`; `import_one_clip` = one clip per lane (`laneN`) at tick 0; `apply_meta(song, text)` (Meta + `about` + `tracks`). Legacy kinds ≤ 39 refused; never panics on a blob that parses. → see `src/import.rs.AGENTS.md`. |
| `src/lib.rs` | `Issue { path (JSON pointer), message }`, `parse` (= `parse_as_is` + `migrate::song`; dotted parameter names stay one pointer segment; unknown field → its object), `load` (parse + validate), `to_json`/`pretty` (2-space, scalar arrays on one line), `features(song)` (conservative `us-*` list from device values). `workers` module behind feature `threads`. |
| `src/main.rs` | CLI `song export\|import\|render\|info\|check\|migrate`; `--bank <dls>\|plus` or env `GM_DLS`; errors `file: /pointer: reason`, exit 1, atomic write, nothing written on failure. → see `src/main.rs.AGENTS.md`. |
| `src/migrate.rs` | `song/1` → `song/2`, `us-patch/1` → `us-patch/2`: `song(&mut Song)` (values by old names → `unisynth::migrate::values` → v3 names; one lane per moving v3 field; structural/era lane → error; effect mode lanes re-encoded per point; quirks a lane reaches set on the device via `um::lane_quirks`; effect trailer dropped), `device` (also presets). |
| `src/model.rs` | Serde model, `deny_unknown_fields`: `Song`, `Meta`, `About`, `Clip`, `Note` `[start,len,pitch,vel]`, `Point` `[tick,value]`, `Track`, `Receive { from, channel, send, volume }`, `Channel`, `Device`, `Placement`, `Lane`, `Values` (ordered name → f32, duplicate key rejected). `FORMAT` song/2, `FORMAT_V1` song/1. → see `src/model.rs.AGENTS.md`. |
| `src/patterns.rs` | Pattern detection for import (design P1–P4 of add-import-patterns): `split(song)` per one-clip lane → `GRIDS` 8/4/2 bars, `plan`: cut points = grid lines no note strictly crosses, identical segment = same clip, variant = ≥ ½ notes of the larger matched (pitch, start ± bar/64) vs an earlier base of the same length → `<base>.<n>`, else next `letters(i)` (`A`…`Z`, `AA`); back-to-back repeat of a whole-length clip → one looping placement; last placement cut at the song length; cost = distinct notes + `PLACEMENT_COST` 8 per placement, least wins (ties → longer grid). Clip ids `<first track id>/<name>`; every track playing the lane gets the same placements. Skips clips with wheel/bend and songs over `MAX_WINDOWS` 2-bar windows. Notes never move in absolute time → export unchanged. |
| `src/preset.rs` | `us-patch/2` `Preset { format, name, kind, values, samples? }`: `save` (non-default values sorted by param index; effect `mode` always kept), `load` (fresh device, others default), `parse` (validated names/ranges; a `us-patch/1` file migrates via `migrate::device`), `to_json`. |
| `src/render.rs` | `render(blob, bank)` → whole-song interleaved f32 through `Player<UDevice, Xorshift::new(SEED=1)>` (CLI and DAW bounce), `wav(samples, rate, float)` (16-bit = player's `clamp(trunc(x·32767))`, or f32). `render_threads(blob, bank, n)` (feature `threads`): `Player::render_f32_par` on `workers::with_workers(n)`, n ≤ 1 = `render`; bit-identical. `load(blob, bank)` → length in frames: builds the player without rendering (load-all check). See change: add-synth-threads. |
| `src/tables.rs` | Parameter tables: `Param { index, name, group, default, law, unit, min, max, options, structural, raw }`, `Table { kind, mode, label, params }`, `table(kind, mode)`, `tables()`, `of_device`, `mode_of`, `kind_name`, `mode_names` (chorus: Chorus, One tap), `EFFECT_MODES` (+ chorus 1, add-tf3-import). Kind 64 from `unisynth::params`; effects = `mode` + legacy-order names with editor defaults. → see `src/tables.rs.AGENTS.md`. |
| `src/validate.rs` | `validate(song)` → every `Issue` with its JSON pointer: header, `/meta/*`, `about`, clips/notes, tracks, receives (incl. master send, `send` > `OUT_PAIRS`, cycles), devices (legacy kind → synth-convert, unknown/out-of-range values, samples, speech, `trailer`), placements, lanes (unknown/structural/duplicate), clip wheel/bend conflicts. → see `src/validate.rs.AGENTS.md`. |
| `src/workers.rs` | Feature `threads`: `Pool` (`new(helpers)`, `helper()` blocking helper body, `stop()`, `Par`; also used by `synth-wasm` with Web Worker helpers, add-wasm-threads) + std spawner `with_workers(n, f)` (n−1 scoped helpers, stopped also on panic). `Pool: Par`: `run` = barrier (every helper joins every run, jobs from a shared counter, caller takes jobs too; ≤ 1 job or no helpers → inline; job panic resumed on the caller after the barrier). Wait: spin 64 → 2000 `yield_now` → park on condvar (measured, `research/size-threads`). Tests: every job once and `run` waits, park/wake, panic propagation, externally started late helpers. See change: add-synth-threads. |
| `tests/cli.rs` | Binary: `render` WAV == direct `Player` i16 render of the exported blob (and of the blob file; f32 size); import → check (`loads (song/2,` / `loads (blob,`; old-layout instrument chunk fails), info (names, features); error path printed + no output; `--meta` attribution in `info`, bad meta file reported with its path; import patterns by default (`t1/A`), `--one-clip` (`lane1`, same export), meta track names. `--threads 1/4` WAV == no flag on `project/music/demo`; bad counts fail, nothing written (feature `threads`). |
