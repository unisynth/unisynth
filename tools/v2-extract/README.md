# tools/v2-extract

V2 (Farbrausch) song corpus, reference renders and the loader oracle for change `add-v2-import`.
Usage and the acceptance list: `research/v2-intros.md`. Songs are © their authors and live in `$V2_SONGS`
outside the repo; the reference player is [v2redux](https://github.com/spheenik/v2redux) (CC0), cloned and
built (`cmake -S . -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build`) at `$V2REDUX`.
