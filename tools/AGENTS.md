# tools

bun/shell/python build and verification tools. Each `*.test.ts` runs under `bun test`. Parity tools are opt-in: they skip (exit 0) when their reference material (synth lab, upstream checkouts, v2redux) is absent; third-party code, songs and WAVs are never committed. Long rows have a pull-only sidecar `tools/<dir>.AGENTS.md` next to the directory.

| File | Purpose |
|---|---|
| `check-song-features.sh` | Compo-build check of a unified song: `synth-convert features`, then host `unisynth` render example and i686 core-only build with exactly those features; `--minimal` drops each listed feature and requires a load failure or different audio. Usage `<song> [--minimal] [bank.dls]`. `--minimal` skips `us-osc-sample` (implied by sample sources), `us-matrix` when `us-matrix-add` listed, `us-chunk-wide` when `us-strip` listed. See change: add-v2-import, unify-v2-algorithms 6.5–6.8. |
| `check-unisynth-features.sh` | Feature-set gate for `crates/unisynth`: `cargo check` each single-module set (`MODULES` incl. `us-voice-*`, `us-matrix*`, `us-automation`, `us-osc-combine`, `us-quirk-*`; `FX` `us-fx-*`), groups, none, all, three "everything but voice paths / matrix / automation" sets for `i686-pc-windows-msvc -Zbuild-std=core` and `wasm32-unknown-unknown`, plus `cargo test` of each set (`--no-test` skips); build-only sets with `us-trusted`. Prints `ok [set]` or errors; any warning fails. See change: shrink-unified-synth, unify-v2-algorithms 6.5–6.8. |
| `demo-songs/` | Builds the seven reference demo songs into `project/music`: `songs.json` manifest (sources, upstream licences, per-song title/author/about), `build.ts` (`synth-convert ws\|tfm\|tf4m` → `song import --meta` → `song check`; meta always says "adapted version"; skips absent sources), `names.ts` (track names from WaveSabre refs), `meta/<name>.json` (song/track `about`), `build.test.ts` → see `demo-songs.AGENTS.md`. |
| `social-card/` | Social preview card: `card.html` (1280×640, site tokens, `site/media/daw.jpg` tilted in, wordmark, lede, 4 stats; the songs stat is hand-kept), `render.sh` (headless Chrome, env `CHROME`) → `site/social.png`. Used as `og:image`/`twitter:image` by `site/index.html`, `packages/daw/src/index.html`, `tools/song-page/build.ts`; also the GitHub repo social preview (uploaded by hand in Settings). |
| `song-page/` | Listening page for every song in `project/music/**`, played live in the browser by the synth (no audio files): `build.ts [out]` (exports blobs, wasm, `index.html`; env `BANK_URL`, `CONTACT`, `ONLY`, `JOBS`), `serve.ts [dir] [port]` (6480, byte ranges, `GM_DLS` at `/daw/data/bank.dls`), `build.test.ts`. Exports `songFiles`, `groupOf`, `slugOf`, `needsBank`, `GROUPS`, `page` → see `song-page.AGENTS.md`. |
| `synth-parity/` | Shared audio parity metrics (ws-parity, tf-parity, unisynth-parity). `metrics.ts`: `readWav`/`writeWav` (16-bit / f32), `loudness` (BS.1770-4 integrated LUFS, −70/−10 gates), `octaveLtas` (63 Hz–16 kHz, Hann 8192/4096), `onsets` (log spectral flux 1024/64, peak > 1.5·local mean + 0.1·max), `alignment(ours, ref, maxLag)` (onset-strength cross-correlation: lag, corr; its curve `novelty(onsetFlux(a), rate)` is exported for windowed use), `compare(ours, ref, tol)` → `Report` (`DEFAULT_TOL` 1 dB / 3 dB / 100 frames / 95 %; `Tolerance.bandFloorDb` default `BAND_FLOOR_DB` 60, `Tolerance.onsetAlignment`), `formatReport`. `cli.ts <ours.wav> <ref.wav> [--onset-frames N] [--json]` exits 1 on FAIL. `metrics.test.ts`: 997 Hz = −3.01 LUFS, gating, band placement, tilt, onset shift 60 ok / 300 fail, alignment, band floor. |
| `tf-extract/` | Tunefish 4 `.tfm` songs out of Brain Control's intro exes (Tunefish 3 intros: `tf3-extract/`) under Wine (`ws-dump` image): `dump.py <exe> <slug> [secs]` (scans process memory for `INST`, validates header counts land on `SONG`/`ENDS`, writes `/out/<slug>-<n>.tfm`; `RAW=1` dumps writable regions to `/out/<slug>.raw`), `make-demos.py [<dir>]` (default `~/Downloads/64k-tools/bc-intros`; `SONGS` aten-hotep, naumachia-insianis → `project/music/released/<slug>.song.json` with meta: Skyrunner credit, pouet url, tf-parity numbers, "no licence, pending permission"; track names `<Role> (Tunefish)` via `ws-extract/make-demos.py` `role`), `README.md` (BC intros by engine). |
| `tf-parity/` | Opt-in Tunefish reference parity (`crates/tfsynth`). `build-ref.sh`: clones `paynebc/tunefish` @ 7e48ce8 into `$TF_REF` (default `/tmp/tf-ref`), builds upstream player + synth + our MIT `render-ref.cpp` (own song length, skips empty instruments) → `$TF_REF/build/render-ref <song.tfm> <out.wav> [tail]`. `parity.ts`: `cargo --example render` vs reference, `compare` with `TOL` (1 dB / 3 dB / onsets 512 frames); songs from `TF_SONGS` or `$TF_REF/media/tf4modules`; no reference → skipped, exit 0. `parity.test.ts`: tolerance, skip path; full run `TF_PARITY=1`. |
| `tf3-extract/` | Tunefish 3 songs out of Brain Control's released intro exes, no Wine (change add-tf3-import 6.1–6.2): `unpack.py <exe> <img>` emulates the kkrunchy stub (`uvx --with unicorn --with pefile`) until the first API call and dumps the image; `extract.py <img> <out.e3prj> [--names prj]` finds the synth block (32 flags, parameter-major bytes: ranged = Transplant, percent = Train Control; song) → `.e3prj`; `make-demos.py` → `project/music/released/{transplant,train-control}.song.json` (meta, parity). When no current-format block exists, `find_old` reads the older Pandora layout through the bit reader `Bits` (bounded): u8 count, per instrument 99 percent bytes (98 = GainAmount) + slot, then the song with packed arrays (`min + v·step`, any width) and skip-coded cell words; it writes a current-format `.e3prj` with BP, notch and effects off (add-tf3-pandora 2.1; spec §10). `extract.test.ts`: synthetic older, truncated and current-format images. Images and projects stay in `~/Downloads/64k-tools/bc-intros/out`. |
| `tf3-parity/` | Opt-in Tunefish 3 (Enigma Studio 3) reference renderer, feature survey and YouTube capture check (change add-tf3-import); `e3prj.ts` project reader, `build-ref.sh` + MIT `shim/` + `render-ref.{cpp,ts}`, `survey.ts`, `captures.sh`, `capture.ts`. → see `tf3-parity.AGENTS.md` |
| `unisynth-parity/` | Opt-in parity, speed, size and drift of the unified synth vs legacy engines, V2 (`v2redux`) and XM (`openmpt123`) references: `parity.ts` (device + reference songs, `retirement`, `report.md`), `v2.ts`, `cauldron.ts`, `cauldron-compact.ts`, `drift.ts`, `songs-drift.ts`, `quirk-survey.ts`, `load-all.ts` (each + `*.test.ts`), generated reports `*.md`, sign-offs `*signoff.json` → see `unisynth-parity.AGENTS.md`. |
| `v2-extract/` | V2 (Farbrausch) corpus, reference renders and oracles in `$V2_SONGS`: `v2.ts gather\|carve\|render\|survey\|check\|oracles`, `dump.cpp` / `events.cpp` / `solo.cpp` (v2redux loader, sequencer, solo oracles), `cmp.ts`, `make-demos.py` (→ `project/music/released/v2/`; `WITHDRAWN` composers (Cyborg Jeff, removed on request) are skipped; `modland_ftp/<Author>--[coop-<Other>--]<title>.v2m` = files from modland's V2 dir (mirror URL); `release/<Author>--<title>.v2m` = carved from a release exe after `upx -d`, credits in `RELEASES`; `PERMITTED` author → permission text instead of `LICENCE`, Teo 2026-11-09), `v2.test.ts`, `README.md`. Skips when v2redux absent → see `v2-extract.AGENTS.md`. |
| `ws-extract/` | WaveSabre song blobs out of released intro exes under Wine: `Dockerfile`, `dump.py <exe> <name> [secs]` (scans process memory, validates the format), `runall.sh` (`JOBS`), `make-demos.py` (→ `project/music/released/<slug>.song.json`, 26 songs; `PERMITTED` music author → permission text, Teo), `README.md` (limits) → see `ws-extract.AGENTS.md`. |
| `ws-parity/` | Opt-in device parity vs upstream WaveSabre, per-device song blobs rendered by both engines. `ws-parity.ts`: `labDir()` (`WS_LAB`, default `~/Downloads/64k-tools/synth-lab/WaveSabre`; absent → skipped, exit 0), `buildUpstream` (clang++ incremental into `build/ws-parity/obj`: upstream core minus GsmSample/GmDls + PlayerLib SongRenderer/Track/CriticalSection + `shim/` + `render-device.cpp`, `-lgsm`), runs `cargo --example render_device` (`wavesabre`; `GM_DLS` adds Adultery songs), `snr` per song, `MIN_SNR_DB` 60, exit 1 below. `render-device.cpp`: our MIT harness, 1 thread, 100-frame `RenderSamples` steps → 16-bit WAV. `shim/`: Win32 pthread `Windows.h`, empty `MSAcm.h`/`mmreg.h`, libgsm WAV49 `GsmSample_mac.cpp`, `$GM_DLS` `GmDls_mac.cpp`. `ws-parity.test.ts`: snr law, skip path; full run `WS_PARITY=1`. |
