# Legacy engines against the unified synth: packed size, six songs, several compile configurations

Generated by `research/size-compare/compare.sh`. Each cell is an i686 `no_std` probe (`research/{ws,tf,us}-size-probe`) that embeds the song, renders all of it and exits with a checksum, so the bytes are the engine code plus the song. Legacy = the WaveSabre port or the Tunefish port with exactly the devices the original song uses, playing the original `.bin`/`.tfm`; unified = `unisynth` with exactly the features `synth-convert features` lists, playing the converted song built in as Rust (`synth-convert rust`, `us-trusted`). Packed with squishy 0.1.3 (the compo packer; `xz -9e` in the second table as a packer-independent proxy).

Configurations (opt-level, then core): `z` `s` `3` use the precompiled core with `panic=abort`; `bz` `bs` `b3` rebuild core (`-Zbuild-std=core,compiler_builtins`, `compiler-builtins-mem`, `panic=immediate-abort`), `bz` and `bs` with `optimize_for_size` (what `tools/build-compo.sh` uses). All: LTO, one codegen unit, `-Ctarget-cpu=pentium4`, `-Zlocation-detail=none`.

## Notes

- Squishy output comes in 512-byte steps, so differences under 512 B are rounding; `xz` is exact.
- Tried and no effect on the unified synth (`bz` plus `-Zmerge-functions=aliases`, plus `-Zinline-mir=no`): byte-identical probes, rows `bz+mf`, `bz+nomir` in `research/size-compare/out/results-v1.csv` (the run before shrink-unified-synth).
- Not possible on i686 in this toolchain: `pentium3` or x87-only (`-sse2`): core refuses to build without `sse2` (float ABI).
