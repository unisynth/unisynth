# tools/unisynth-parity (sidecar: full detail of the AGENTS.md row)

Pull-only (not auto-injected). Opt-in parity, speed, size and drift of the unified synth vs the legacy engines and V2 / XM references. Common settings: 1 dB loudness, 3 dB per octave band 63 Hz–16 kHz with `BAND_FLOOR_DB` 24 (bands > 24 dB below the loudest reference band skipped), onset-strength alignment `MIN_ALIGNMENT` 0.5 (WaveSabre onsets 100 frames, Tunefish 512). Reports hold metrics only, never audio. Renders use `[profile.fast]` (`PROFILE`).
