# project

Song library (LLM-editable). Music: `music/*.song.json` (`song/2`, `schema/song.schema.json`; presets `schema/us-patch.schema.json`; validation in `crates/song`). `music/released/` = converted songs from released intros / exe music (see `music/NOTICE.md`). Third-party songs are published pending the authors' permission and carry no licence.

| File | Purpose |
|---|---|
| `music/demo.song.json` | Example `song/2` (128 BPM, 8 bars): Kick, Bass (Acid Bass + Crusher 66, `filt1.cutoff` lane), Lead (Echo 68), Pad, Verb bus (Cathedral 71) ← Lead/Pad, Master (Compressor 72) ← all. No `meta`. Validated/rendered by `crates/song/tests/demo.rs`, schema-checked by `tests/song-schema.test.ts`. See change: add-synth-daw. |
| `music/NOTICE.md` | Attribution and licences of the seven demo songs (adapted works): original, author as stated upstream, copyright, MIT / GPL-3.0-or-later / CC0-1.0 (turtles). Also §Released songs (no licence, pending permission). |
| `music/patches/*.patch.json` | `us-patch/2` presets `acid-bass`, `glass-pad` (kind 64, non-default values by name). |
| `music/{global-groove,elysian,engage,eladamri,no-remorse,tf4testsong,turtles}.song.json` | Reference songs the A/B renders play, converted by `tools/demo-songs` (WaveSabre test projects, MIT; Tunefish modules, GPL-3.0-or-later; `turtles` from Enigma Studio 4 `zoom.tf4m`, CC0-1.0, via `synth-convert tf4m`).
